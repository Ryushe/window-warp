Installation instructions

Prepare an extension to see its instructions.

  1. In Chrome, open chrome://extensions.
  2. Turn on Developer mode, then select Load unpacked.
  3. Choose the Extension folder shown above.
  4. Open the Window Warp extension in Chrome, paste the code, and select Connect.
  1. In your Firefox profile, open about:debugging#/runtime/this-firefox.
  2. Select Load Temporary Add-on.
  3. Open the Extension folder shown above and choose manifest.json.
  4. Open the Window Warp extension in Firefox, paste the code, and select Connect.

Load it again after Firefox restarts.
